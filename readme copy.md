## Getting Start

Here are some instruction for use this template.

1. Create a React.js project.
2. Copy the code from `template.jsx` into your project.
3. Set up Tailwind CSS in the project.
4. Replace the `tailwind.config.js` file with the one from this template.
5. configure image path
- Put assets folder to `public` folder
- set image path
  - `/assets/dream-job/` to `/assets/images/`
